# 学习路线与外部题单维护

2026-11-12 更新：8 站学习路线，23 道洛谷/牛客示例题。站次是本站教学安排，与课程地图原有阶段、平台官方难度分别标注。

## 使用与边界

- 先在本站学习/实验，再去官方题页读完整题面并提交，最后回本站手动记录状态与一句复盘。
- 不镜像题面或完整题解，不自动读取或同步第三方账号。牛客练习以官方 URL/UUID 标识，竞赛题使用固定 contest/problem URL，不依赖可能变化的短编号。
- 树状数组、最短路、网络流和树链剖分等尚未实现课程明确标为规划。P1886 单调队列需额外先修，不能当作普通双指针演示已完整覆盖。
- 洛谷 P2249 与牛客二分查找-I 的重复值、0/1 起始、函数补全区别在题目提示里列明。本站 KMP 本就支持全部与重叠匹配，P3375 需另核对 1-based 位置和前缀表输出格式。
- 官方链接核查日期 2026-11-12，未执行登录、提交或官方 AC 核验。标题和短引导不代替官方约束。

## 路线

### 第 0 站：语法与第一份提交

先能独立完成编译、运行、读取和输出，再处理简单条件。

达标：不看参考写出完整程序；能解释输入、计算和输出各在哪一行，并验证至少两个边界。

建议：一次只解决一个新问题。提交失败时先检查编译错误和输出格式。

### 第 1 站：循环、数组与模拟

把题目描述变成按顺序更新的状态，练好边界和下标。

达标：能手算每一步状态，独立通过数组遍历和模拟题；说清终止条件、越界风险和提前失败处理。

建议：先列状态表再编码；每题至少保留一个曾写错的反例。

### 第 2 站：基础算法与有序性

从遍历过渡到排序、前缀和、二分和双指针，学会利用结构减少搜索。

达标：能解释二分区间不变量；分清首次出现与任意命中、0/1 起始下标、函数补全与标准输入输出。

建议：先写暴力版本作对照，再检查空、单元素、重复值、首尾命中和不存在。

### 第 3 站：搜索与状态恢复

理解栈、队列、访问标记、回溯撤销和无权最短路。

达标：能独立写 BFS 和一类回溯；解释何时标记访问、何时撤销状态，及为何不会漏解或重复计数。

建议：先在小网格或小棋盘跑通，记录队列/递归栈变化，再扩大输入。

### 第 4 站：递推与综合建模

连接递推、背包、二分答案和字符串匹配，不依赖只会背模板。

达标：对每题写清状态或判定含义、转移/不变量、复杂度；独立构造能击穿错误实现的边界例。

建议：做完不要立刻抄下一题。隔天不看题解重写，并讲清为什么这样写。

### 第 5 站：数据结构与图论进阶

在已掌握基础上学习并查集、单调队列、树状数组和最短路。

达标：能说明每个操作维护的性质和复杂度；处理重复操作、过期状态、不可达及数值范围。

建议：含尚未实现课程，先补官方题解/教材中的必要知识。单调队列不能用普通双指针课替代。

### 第 6 站：远期专题，不急着跳级

逐步补齐进阶图论、区间/树形 DP、数论、网络流和树链剖分。

达标：先完成所有先修，再能解释核心模型和正确性；不要把模板 AC 当作掌握整类问题。

建议：两题仅为远期方向示例，相关课程当前是规划。遇到多个陌生前置知识时先返回补基础。

### 第 7 站：团队限时训练与复盘

从基础阶段就可并行练习读题分工、单机协作、限时决策和赛后复盘。

达标：训练后能列出读题、建模、实现、调试和协作方面的具体改进，并在下一场验证。

建议：从已学题中选少量未做题组成模拟训练，赛后独立补题。不把任何题单包装为已核实 CCPC 真题或奖牌保证。

## 开发与验收

数据集中在 src/practice/catalog.ts。新增题目时核验官方链接、学习目标、关联课程和提示，更新核查日期，保持 stable ID 稳定。

测试覆盖唯一 ID/URL、官方 HTTPS 来源、课程引用、路线覆盖、筛选交集、手动状态、静态渲染、v1 旧备份兼容与畸形数据拒绝。全量执行 npm test 和 npm run build。浏览器验收搜索/组合筛选、无结果清除、刷新保留、前进后退、外链新标签页、路线跳转、移动窄屏、导入取消与导出恢复。

学习数据仍为 algo-expedition-v1。新增 externalProblems 可选字段，旧备份自动补全；无效备份整份拒绝，导入有效文件前确认替换。浏览器无法保存时展示告警，损坏原始存储不自动覆盖。
