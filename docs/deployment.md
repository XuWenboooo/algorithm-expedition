# 发布与维护

## 发布范围

本发布副本保留应用源码、课程内容、参考 C++ 源码、测试和构建配置。原始项目另行保留。未携带原历史交付报告、个人路径、依赖目录、编译后的 exe/obj、环境变量或学习备份。

公开网页不包含后端账号或数据库。不要在 src/ 或 public/ 中加入密钥，前端资源会公开下载。

## 发布前检查

执行 `npm ci`、`npm test`、`npm run build`。C++ 编译失败必须修复，不可用跳过检查来发布。

CI 在 Ubuntu 构建 C++17 参考程序并运行完整测试；网页由 GitHub 官方 Pages Actions 上传。仅部署 main 的推送/手动运行，拉取请求只测试。

## 发布后检查

确认远程 main 的提交与部署任务一致，且 build/deploy 均成功。打开 Actions 返回的实际网址，检查首页、课程直达链接、刷新、前进/后退、播放/暂停/重置、训练记录刷新留存、备份导出/导入与手机窄屏。

## 维护

修改此发布副本的源码，再运行完整检查并推送。部署不依赖本机常驻服务。GitHub Pages 是静态托管，不提供在线 C++ 判题、云端学习记录或账号同步。域名变更前请导出浏览器学习记录。

不要随网站仓库上传个人学习 JSON。后续选择开源许可证或引入第三方课程素材前，请确认权利范围并保留来源及许可证。
